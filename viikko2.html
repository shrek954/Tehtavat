Tämän viikon tehtävänä oli rakentaa GitHub Actions -workflow.

Sisältö

Tehtävässä luotiin workflow, joka suorittaa analyysin automaattisesti repositorioon tehtävien muutosten yhteydessä.

Lisäksi tehtiin analyysiskripti, joka tunnistaa repositoriossa käytettyjä ohjelmointikieliä ja etsii yleisiä ohjelmistosuunnittelun malleja.

Analyysin tulokset tallennetaan raporttiin ja julkaistaan GitHub Actionsin artefaktina.
