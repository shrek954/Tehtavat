Oppimistehtävä 3: React ja Local Storage

Toteutin Vite-pohjaisen React-sovelluksen, joka generoi käyttäjälle satunnaisen koodinimen.

Sovellus tallentaa generoimansa koodinimen selaimen Local Storageen ja hakee saman koodinimen uudelleen käyttäjän kirjautuessa sisään.

Toteutetut vaatimukset

  • Vite React -projekti
  • React-komponentti
  • Satunnaisen koodinimen generointi
  • Local Storage -tallennus
  • Local Storage -haku
  • Koodinimen näyttäminen käyttäjälle
